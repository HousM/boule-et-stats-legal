Suppression des données — Boule&Stats

Application : Boule&Stats · Éditeur : MPRO'ACT SAS · Dernière mise à jour : 14 juillet 2026.

1. Données concernées

Boule&Stats fonctionne en mode invité : aucun compte n'est créé, aucun nom, email ou identifiant personnel n'est demandé ni stocké. Les seules données qui existent sont :

  • Données locales sur votre appareil (100 % chez vous) : historique des tirages téléchargés, grilles enregistrées, préférences d'affichage, confirmation d'âge.
  • Token push anonyme Firebase Cloud Messaging, généré uniquement si vous avez activé l'option « Recevoir les résultats après chaque tirage » dans les Réglages. Ce token n'est pas rattaché à votre identité.

2. Comment demander la suppression

Option A — Suppression immédiate (recommandée)

  • Désinstaller l'application : supprime immédiatement et intégralement toutes les données locales (base SQLite + préférences).
  • Désactiver le switch notifications dans Réglages → Notifications : désabonne le token push des topics côté serveur Firebase, ce qui rend le token inutilisable et le fait expirer sous 60 jours d'inactivité.

Ces deux actions ne demandent aucune démarche auprès de MPRO'ACT et ne nécessitent aucun email.

Option B — Demande explicite par email

Vous pouvez adresser une demande de suppression à l'éditeur :

Email : contact@mproact.com

Précisez dans votre message :

  • Le nom de l'application (« Boule&Stats »).
  • Optionnel : la date approximative d'installation et le modèle d'appareil, si vous souhaitez que nous purgions les journaux techniques associés à votre token (voir §3).

MPRO'ACT répond sous 30 jours ouvrés (délai RGPD).

3. Ce qui est effectivement supprimé, et quand

Donnée Délai de suppression
Base locale SQLite (tirages, grilles)Immédiat (désinstallation)
Préférences (SharedPreferences)Immédiat (désinstallation)
Abonnement aux topics FCMImmédiat (désactivation du switch)
Token FCM côté FirebaseExpire sous 60 jours d'inactivité (mécanisme Google)
Journaux techniques (logs serveur MPRO'ACT)Purge automatique sous 30 jours ; purge sur demande < 7 jours

4. Données conservées après suppression

Aucune donnée personnelle n'est conservée. Les seules données maintenues en base par MPRO'ACT sont les résultats officiels des tirages FDJ (numéros gagnants publics, dates, jackpots), qui ne sont pas des données personnelles.
